Never paste a classic token with broad account permissions. The token is used in this browser session only and is not saved to localStorage or included in the site files.

How to create the token

Do this once in GitHub, then paste it here when you want to publish.

1

Open GitHub Fine-grained tokens ↗ and create a new token.

2

Under repository access choose Only select repositories and select Rajatsinghboss/rajatsinghboss.github.io.

3

Under repository permissions, set Contents to Read and write. Leave all other optional permissions off. Generate and copy the token.

4

Return to this admin page, paste the token, select Load latest if you want to refresh your settings, then choose Publish changes.

5

Wait for GitHub Pages to publish the new commit, then refresh your public store. The token is cleared after a successful publish.
